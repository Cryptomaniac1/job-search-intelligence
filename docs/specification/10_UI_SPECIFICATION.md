The implemented Interview Pipeline dashboard includes summary metrics, schedule/status/type/company
and date filters, a linked job/recruiter list, and a detail timeline showing immutable extraction
evidence. An empty live schema displays “No interview events have been imported yet.” and never
uses fabricated sample data. Sanitized examples are available only through the documented
temporary demo command.
